# Makky Film Pipeline

An automated, code-driven studio workflow for generating viral singing ads, dramatic narrative stories, and high-converting commercial videos using open-source AI models.

## Pipeline Architecture
1. **The Writer:** Automated scriptwriting and direct-response hook generation.
2. **The Visuals:** Character-consistent image prompting and scene video generation.
3. **The Voice:** Custom singing voiceovers and audio tracks.
4. **The Assembly:** Programmatic video stitching and automated caption formatting.
